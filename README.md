Program Rekap dan Analisis Nilai Matematika Siswa

Deskripsi Proyek

Program Rekap dan Analisis Nilai Matematika Siswa merupakan proyek sederhana menggunakan bahasa pemrograman Python untuk membantu mengolah data nilai siswa.

Program ini dirancang untuk menghitung rata-rata nilai, mencari nilai tertinggi dan terendah, serta mengetahui jumlah siswa yang lulus dan tidak lulus berdasarkan KKM.

Tujuan

1. Mempermudah pengolahan nilai matematika siswa.
2. Mengurangi kesalahan dalam perhitungan nilai.
3. Menampilkan hasil analisis nilai secara sederhana.

Fitur Program

- Membaca data nilai siswa.
- Memvalidasi nilai dari 0 sampai 100.
- Menghitung rata-rata nilai.
- Menentukan nilai tertinggi dan terendah.
- Menghitung jumlah siswa lulus dan tidak lulus.
- Menyimpan laporan hasil analisis.

Teknologi yang Digunakan

- Python
- Visual Studio Code
- Git dan GitHub

Cara Menjalankan Program

Program akan dijalankan melalui terminal menggunakan Python.

Perintah menjalankan program:

python src/main.py

Pengujian

Pengujian dilakukan menggunakan beberapa kondisi, seperti:

- Nilai normal.
- Nilai minimum 0.
- Nilai maksimum 100.
- Nilai di luar rentang.
- File data tidak ditemukan.
- Kondisi seluruh siswa lulus.
